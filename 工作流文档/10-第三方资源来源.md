## 16. 第三方素材资源库来源

- Pexels：https://www.pexels.com/；凭据只从 `PEXELS_API_KEY` 环境变量读取，不在文档中保存明文。按当前供应商配额限流，本工作流请求上限默认每小时 200 次，响应要求更低时使用更低值。

- Pixabay：https://pixabay.com/；凭据只从 `PIXABAY_API_KEY` 环境变量读取，不在文档或示例链接中保存明文。查询词由实际用户创意、内容模块与构图需求生成，按需要采集图片或视频，不用固定示例关键词牵引产品主题。

- Unsplash：https://unsplash.com/；核对选定图片与实际下载途径的许可、使用范围和归因/API 规则，不将公开可见误认为无限制许可。可作为真实摄影的独立发现来源。

- Wikimedia Commons：https://commons.wikimedia.org/；按每个文件页核对作者与具体许可，准确履行 CC 等许可的署名/修改说明及适用要求，不能只凭网站名称认定可用。

无图库凭据或商业图库网页受限时，优先尝试 Commons 的公开 MediaWiki API：`https://commons.wikimedia.org/w/api.php`。使用 `action=query`、`generator=search`、`gsrnamespace=6`、`gsrsearch=<实际主题英语查询>`、`gsrlimit=10`、`prop=imageinfo`、`iiprop=url|mime|size|extmetadata` 与 `format=json`，查询参数须正确 URL 编码；不要把 API 返回的 JSON 当图片。逐项读取 `imageinfo` 中的来源页/下载 URL 和 `extmetadata` 中的作者、许可名称、许可 URL、署名与使用限制，再打开候选图核对实际对象。信息缺失、非摄影、用途不兼容或不能履行许可义务时淘汰；不以公开 API 可访问等同授权。页面搜索可用时也可通过 `Special:MediaSearch` 发现候选。API 也被拦截时继续其他已列来源；遵守第 0.6 节预算，不绕过访问控制。

- LottieFiles：https://app.lottiefiles.com/（只使用免费且许可明确的素材）

- Pinterest：https://www.pinterest.com/（仅用于视觉研究）

- App 研究参考：https://app.diandian.com/rank/line-1-0-0-24-0-3-0?time=1790006400000-1790045578928&order=1&upkind=0&name=&count=&percent=

- 可选本地资源工作流：`/Applications/config/resource_download_manager/SKILL.md`；存在时完整读取并使用匹配流程。该工具不是网站搜索的必需前提，另一台机器没有此文件时，按第 10.6 节使用实际可用的搜索、浏览器或正式 API 进行真实照片发现与合法采集，不因固定路径缺失直接改成插画或省略网站搜索。

- Logo 唯一生成入口：http://stargate.local:3100/image；仅用于当前项目的 Logo，禁止用于生成 App 内容照片、封面、背景、视频帧或其他本地内容图片。内容照片/图片必须通过上列第三方网站或其正式资源 API 搜索、核验来源与许可后下载，具体执行和回退规则见第 2.5、10.6 节。

第 10.7 节的最终图片加载复验和缺图补齐，仅从以上已列网站中搜索并下载相关主题图片，按第 10.6 节逐项核对源文件许可、归因和实际展示。不得把其他图片生成服务、Stargate Logo 入口或搜索结果缩略图当作第三方主题图片来源。

竞品、Pinterest 和研究链接只用于研究信息层级、交互模式和搜索关键词，不复制其品牌、文案、Logo 或未获授权的素材。Pexels、Pixabay、Unsplash、Wikimedia Commons 等用于第 10.6 节的真实照片发现；每个最终摄影文件仍需核对实际许可、使用范围与归因要求。LottieFiles 仅提供补充动效，不能算真实照片。依法取得许可的图片/视频可按第 10 节审核并随包使用，不能把“研究参考不许照搬”误解为禁止合规素材。Stargate 仅生成 Logo，App 内容照片/摄影封面须来自可追溯且许可明确的第三方来源；原生图标、代码绘制矢量符号、装饰插画、渐变和 Emoji 等非摄影 UI 素材不受照片网站来源要求约束，也不计入真实照片数量。
