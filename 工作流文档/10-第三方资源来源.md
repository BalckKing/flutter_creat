## 16. 第三方素材资源库来源

可直接使用 Google 图片搜索，按主题找到原图与来源、核对许可并下载到当前工程 `assets/media/`，不把 Google 搜索预览图或热链作为 App 运行资源。它是素材发现入口，授权依据仍来自对应的原始来源；不可访问时切换下列来源并遵守第 10.6 节的有限尝试规则。不同独立内容展示位使用不同图片，最终运行与断网验收只使用已落盘并打包的本地资源。

任何图片生成或下载前，先创建用户项目名称对应的专属暂存目录 `~/Downloads/<sanitized-project-name>/`；本机为 `/Users/admin/Downloads/<sanitized-project-name>/`。在该目录下分别使用 `content/`、`backgrounds/`、`logo-candidates/` 和 `exports/`，禁止直接写入公共 Downloads 根目录或其他项目目录。许可、格式、哈希和去重核验后，才把选定文件复制到当前工程 `assets/`；运行时不引用 Downloads 路径，也不将暂存目录打包。

以下是开发期检索渠道，不是 App 需要展示的来源列表。图片、视频选材优先使用实际许可及下载/API 条款允许用途且无需公开署名的素材；具体候选逐项核验，不按平台名称一概判定。公开展示与内部记录分离，统一执行第 10.1.1 节。

- Pexels：https://www.pexels.com/；凭据只从 `PEXELS_API_KEY` 环境变量读取，不在文档中保存明文。按当前供应商配额限流，本工作流请求上限默认每小时 200 次，响应要求更低时使用更低值。

- Pixabay：https://pixabay.com/；凭据只从 `PIXABAY_API_KEY` 环境变量读取，不在文档或示例链接中保存明文。查询词由实际用户创意、内容模块与构图需求生成，按需要采集图片或视频，不用固定示例关键词牵引产品主题。

- Unsplash：https://unsplash.com/；核对选定图片与实际下载途径的许可、使用范围和归因/API 规则，不将公开可见误认为无限制许可。可作为真实摄影的独立发现来源。

- Wikimedia Commons：https://commons.wikimedia.org/；按每个文件页核对作者与具体许可，准确履行 CC 等许可的署名/修改说明及适用要求，不能只凭网站名称认定可用。

无图库凭据或商业图库网页受限时，优先尝试 Commons 的公开 MediaWiki API：`https://commons.wikimedia.org/w/api.php`。使用 `action=query`、`generator=search`、`gsrnamespace=6`、`gsrsearch=<实际主题英语查询>`、`gsrlimit=10`、`prop=imageinfo`、`iiprop=url|mime|size|extmetadata` 与 `format=json`，查询参数须正确 URL 编码；不要把 API 返回的 JSON 当图片。逐项读取 `imageinfo` 中的来源页/下载 URL 和 `extmetadata` 中的作者、许可名称、许可 URL、署名与使用限制，再打开候选图核对实际对象。信息缺失、非摄影、用途不兼容或不能履行许可义务时淘汰；不以公开 API 可访问等同授权。页面搜索可用时也可通过 `Special:MediaSearch` 发现候选。API 也被拦截时继续其他已列来源；遵守第 0.6 节预算，不绕过访问控制。

- LottieFiles：https://app.lottiefiles.com/（只使用免费且许可明确的素材）

- Pinterest：https://www.pinterest.com/（仅用于视觉研究）

- App 研究参考：https://app.diandian.com/rank/line-1-0-0-24-0-3-0?time=1790006400000-1790045578928&order=1&upkind=0&name=&count=&percent=

- 可选本地资源工作流：`/Applications/config/resource_download_manager/SKILL.md`；存在时完整读取并使用匹配流程。该工具不是网站搜索的必需前提，另一台机器没有此文件时，按第 10.6 节使用实际可用的搜索、浏览器或正式 API 进行真实照片发现与合法采集，不因固定路径缺失直接改成插画或省略网站搜索。

- 可选 Stargate 图像生成入口：http://stargate.local:3100/；生图网站、工具和模型不要求统一，可按题材选用其他实际可用来源，以精致美观、主题准确、材质/光影自然及完整构图验收；该入口可用于生成当前项目 Logo，以及按第 6.11 节选择生图路线的页面主题背景装饰图案。背景也可直接动画生成、程序制作或第三方组件合成，动画工具与服务不限，清单不是白名单，不强制每页重新生成图片，但每页必须有真实半透明主题图片点缀，不能由动画/程序场景替代；实际背景图片保存到 `assets/backgrounds/<page_id>/<page_id>_background.png`，按页面 ID 分类命名并接入对应页面；该用途不扩展为内容摄影来源。禁止用它生成或替代 App 内容照片、实景封面/摄影背景、视频帧或其他需要真实摄影的主题内容。真实内容照片必须通过上列第三方网站或其正式资源 API 搜索、核验来源与许可后下载，具体执行和失败回退见第 2.5、6.11、10.6 节。

第 10.7 节的最终图片加载复验和缺图补齐，仅从以上已列网站中搜索并下载相关主题图片，按第 10.6 节逐项核对源文件许可、归因和实际展示。不得把其他图片生成服务、Stargate Logo 入口或搜索结果缩略图当作第三方主题图片来源。

竞品、Pinterest 和研究链接只用于研究信息层级、交互模式和搜索关键词，不复制其品牌、文案、Logo 或未获授权的素材。Pexels、Pixabay、Unsplash、Wikimedia Commons 等用于第 10.6 节的真实照片发现；每个最终摄影文件仍需核对实际许可、使用范围与归因要求。LottieFiles 可提供许可适用的动画素材，也可选择其他动画工具、服务或组件合成，例举来源不构成限制；动画不能算真实照片。依法取得许可的图片/视频可按第 10 节审核并随包使用，不能把“研究参考不许照搬”误解为禁止合规素材。Stargate 用于 Logo 和第 6.11 节限定的页面背景装饰；App 内容照片/摄影封面须来自可追溯且许可明确的第三方来源。原生图标、代码绘制矢量符号、装饰插画、渐变和 Emoji 等非摄影 UI 素材不受照片网站来源要求约束，也不计入真实照片数量。
